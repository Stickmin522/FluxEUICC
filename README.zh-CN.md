# FluxEUICC

FluxEUICC 是一款基于 [OpenEUICC](https://gitea.angry.im/PeterCxy/OpenEUICC) 的 Android 可拆卸 eSIM 管理应用。

## 功能

- 扫描二维码或输入激活码，下载 eSIM 套餐。
- 启用、停用、重命名和删除套餐。
- 查看卡片信息，并使用兼容的 USB CCID 读卡器。
- 选择支持的界面语言或跟随系统语言。
