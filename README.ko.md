# FluxEUICC

**eSIM 프로필을 간편하게 추가하고 전환하며 관리하세요.**

FluxEUICC는 [OpenEUICC](https://gitea.angry.im/PeterCxy/OpenEUICC)를 기반으로 하는 Android용 탈착식 eSIM 카드 관리 앱입니다. 여러 프로필을 보기 쉬운 화면에 모아 루팅 없이 일상적인 다운로드, 전환 및 관리를 할 수 있습니다.

## FluxEUICC의 장점

- **현대적이고 명확한 화면**: 카드 형태의 프로필 목록, 직관적인 활성화 상태 표시, 간결한 메뉴로 자주 쓰는 기능을 쉽게 찾을 수 있습니다. 시스템 테마 색상과 적응형 아이콘도 지원합니다.
- **더 빠른 전환 결과 확인**: 프로필 전환 후 재연결 대기를 최적화하고 작업 결과를 명확하게 알려 주어, 오래 기다리는 동안의 불확실성을 줄입니다.
- **9개 인터페이스 언어**: 기본적으로 시스템 언어를 따르며, 지원되는 언어를 직접 선택할 수도 있습니다.
- **최신 Android 기기에 맞춘 설계**: Android 17에 맞게 설계되었으며, 64비트 ARM 기기를 위한 화면 전체를 활용하는 레이아웃과 뒤로 가기 제스처를 지원합니다.

## 주요 기능

- QR 코드를 스캔하거나 활성화 코드를 입력해 새 eSIM 프로필을 다운로드합니다.
- 설치된 프로필을 확인하고 활성화, 비활성화하거나 사용 중인 프로필을 전환합니다.
- 프로필 이름을 변경하고 필요 없는 프로필을 삭제해 eSIM 목록을 정리합니다.
- 카드 정보를 확인하고 기기 호환성을 점검하며, 호환되는 USB CCID 리더기로 카드를 관리합니다.

## 지원 언어

영어, 중국어 간체, 중국어 번체, 일본어, 한국어, 아랍어, 프랑스어, 독일어, 스페인어.

시스템 언어가 지원되지 않으면 영어로 표시됩니다.

## 다운로드 및 사용 방법

현재 버전: **1.1.2**. [다운로드 페이지](https://github.com/Stickmin522/FluxEUICC/releases/latest)에서 APK를 받을 수 있습니다.

1. Android 9 이상을 실행하는 64비트 ARM 기기에 앱을 설치합니다.
2. OpenEUICC와 호환되는 탈착식 eSIM을 삽입하거나 호환되는 USB 리더기를 연결합니다.
3. 휴대폰의 SIM 슬롯에서 사용하는 카드는 FluxEUICC의 서명 인증서를 허용하도록 설정해야 합니다. 필요한 인증서 지문은 앱 설정에서 확인하고 복사할 수 있습니다. 자세한 설정 방법은 릴리스 페이지의 사용 설명을 참고하세요.
4. 프로필을 추가하고 활성화할 eSIM을 선택합니다.

사용 가능한 기능은 휴대폰, 카드 및 리더기의 호환성에 따라 달라집니다. 전환 후 네트워크가 복구되는 시간은 카드와 휴대폰 시스템에 따라 달라집니다.
